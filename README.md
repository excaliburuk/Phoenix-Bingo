# Phoenix Bingo Standalone

A dual-screen Windows desktop Bingo & Music Bingo player built for live parties, community events, charity nights, and venue hosts. Run the entire show from your laptop while projecting a clean, distraction-free stage display to an external TV or projector.

**👉 To download the latest version, click the "Releases" tab on the right side of this page.**

---

## ✨ Key Features

### 🖥️ Dual-Screen & Single-Screen Display Modes
- **Host Control Console:** Full game management, number/track calling, board tracking, and winner verification on your primary laptop screen.
- **Borderless Stage Display:** Automatically detects and targets secondary monitors/TVs for a full-screen audience view with zero spoilers or host controls.
- **Single-Screen Preview:** Built-in embedded stage preview when running on a single laptop screen.

### 🎱 Classic 90-Ball & Boozy Bingo
- **Interactive 1–90 Calling Board:** Smooth animations, clear last-number callouts, and instant visual board history.
- **Multiple Win Patterns:** Support for **1 Line**, **2 Lines**, and **Full House** rounds.
- **Built-in Sound Effects & Voice Callouts:** Crisp audio cues, drumrolls, fanfare, and optional caller voice announcements.
- **Ticket Verification:** Quick winner check against issued ticket sets (`.mbtickets`).

### 🎵 Music Bingo Player Mode
- **Card Set Playback (`.mbcards`):** Load custom Music Bingo playlists and unique 5×5 player card sets created with *MusicBingoCreator*.
- **Smooth Audio/Video Playback:** Powered by LibVLC for reliable clip playback with automatic fade-ins/fade-outs and gain normalization.
- **Stage Visualizers & Placeholder Loops:** Plays themed or bundled background placeholder videos and audio-reactive visualizers during audio-only tracks so the big screen always looks alive.
- **Targeted & Random Draw Modes:** Full support for standard shuffled draws as well as targeted game sequences, complete with automatic session persistence and crash/resume recovery.

### 🎨 Custom Event Branding
- **Event & Venue Customization:** Personalize the stage screen with your own event name, custom color theme, and event logo (`logo.png`), while keeping attribution clean and compliant.

---

## 💻 System Requirements
- **OS:** Windows 10 or Windows 11 (64-bit)
- **Runtime:** .NET 8.0 Desktop Runtime (Windows x64) — *included if using the self-contained release*
- **Display:** Single screen or Dual-screen setup (HDMI / wireless display recommended for the audience Stage screen)

---

## 🚀 Quick Start
1. Download and extract the latest release archive (or run the installer) from the **Releases** tab.
2. Connect your external TV or projector in **Extend** mode (`Win + P` → *Extend*).
3. Launch **Phoenix Bingo Standalone**.
4. Choose your game mode, load your ticket or `.mbcards` set if applicable, and start calling!
