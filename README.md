# Phoenix Bingo Standalone

A complete, all-in-one dual-screen Windows desktop **90-Ball & 75-Ball Bingo** caller, stage display, and **printable ticket generator** built for live parties, community events, charity nights, and venue hosts. Run the entire game from your laptop while projecting a crisp, full-screen bingo board and live number callouts to an external TV or projector—and generate custom-branded printable tickets directly from the app.

## ✨ Key Features

### 🎱 Dual Game Formats: 90-Ball & 75-Ball Bingo
* **90-Ball UK Bingo Mode:** Classic 1–90 grid layout with traditional bingo lingo/callouts, supporting **1 Line**, **2 Lines**, and **Full House** rounds.
* **75-Ball US/Pattern Bingo Mode:** Classic B-I-N-G-O (1–75) column layout with letter-number callouts (`B-12`, `G-54`, etc.) and flexible winning pattern support (Lines, Four Corners, Blackout/Full Card, and custom patterns).
* **Instant Mode Switching:** Switch effortlessly between 75-ball and 90-ball games between rounds without restarting the app.

### 🎟️ Built-In Ticket Generator & Winner Verification
* **Generate Printable Tickets:** Create unique, valid **90-ball strips** (6-ticket strips covering all 90 numbers) or **75-ball bingo cards** directly inside the application—no external generator required.
* **Print-Ready Export & `.mbtickets` Support:** Export print-ready ticket sheets for your guests while saving the matching `.mbtickets` set for instant digital verification during play.
* **Fast Winner Verification:** Enter a ticket serial number or claimed numbers to immediately verify a valid **1 Line**, **2 Lines**, **Full House**, or **75-Ball Pattern** win without slowing down the room.
* **Persistent Session Recovery:** Automatically saves active board state so an accidental close or interruption never loses your current game.

### 🎨 Installable Branding for Stage & Printed Tickets
* **Installable Branding Packages:** Install custom branding packages (`.ppgsbrand` / `.zip` with custom `logo.png` and event settings) directly through the UI.
* **Branded Printed Tickets:** Automatically applies your installed event logo, title, and footer details onto generated printable bingo tickets so every sheet matches your venue or event.
* **Branded Stage Display:** Customizes the audience Stage screen with your installed logo, colors, and event details while keeping Phoenix Parties attribution clean and compliant.

### 🖥️ Dual-Screen & Single-Screen Display Modes
* **Host Control Console:** Full game management, manual or auto-draw number calling, board tracking, call history, ticket generation, and winner verification on your primary laptop screen.
* **Borderless Stage Display:** Automatically detects and targets secondary monitors/TVs for a crisp, full-screen audience view showing the current ball, recent calls, and the live master board.
* **Single-Screen Preview Mode:** Built-in embedded stage preview when running on a single laptop or desktop screen.

### 🔊 Voice Callouts & Sound Effects
* **Caller Voice Announcements:** Built-in audio voice packs for clear number and bingo lingo announcements.
* **Custom Audio & SFX:** Includes celebratory fanfare, drumrolls, and callout chimes with volume and mute controls.
* **Auto-Call Timer:** Optional configurable auto-draw timer for hands-free calling, alongside manual one-click or spacebar draw controls.

## 💻 System Requirements
* **OS:** Windows 10 or Windows 11 (64-bit)
* **Runtime:** .NET 8.0 Desktop Runtime (Windows x64) — *included if using the self-contained release*
* **Display:** Single screen or Dual-screen setup (HDMI / wireless display recommended for the audience Stage screen)

## 🚀 Quick Start
1. Download and extract the latest release archive (or run the installer).
2. *(Optional)* Install your custom branding package to apply your logo and event details to both the Stage screen and printed tickets.
3. Use the built-in **Ticket Generator** to print your 90-ball strips or 75-ball cards and save the `.mbtickets` file.
4. Connect your external TV or projector in **Extend** mode (`Win + P` → *Extend*), launch **Phoenix Bingo Standalone**, and start calling!
